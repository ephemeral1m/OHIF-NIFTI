# NIfTI display and focus repair — 2026-09-17

## User-visible behavior

- Clicking a target name selects it, jumps to an occupied voxel, and highlights for 850 ms. The separate location button is removed.
- Stack uses the source slice index. MPR uses the same voxel through the complete voxel-to-LPS affine. Empty targets select without a jump.
- Each target has independent fill opacity, fill/outline mode, outline opacity/width, inactive visibility and inactive intensity.
- Group opacity is a multiplier (initially 100%). Target fill starts at 45%, outline at 100%. Hiding a group preserves individual visibility and style choices.
- View settings last for the current open case only. Save All continues to save masks and metadata; it does not persist these display preferences.
- Focus highlights at the viewport style scope, requests segmentation renders, and restores current settings after completion/cancellation. It does not change color, voxels, revision, or saved history.
- A selected target is revealed; a completely empty target can be selected for editing. The pulse respects fill/outline mode. Full hidden-group state is intentionally made visible when selecting a target.

## Visual conventions

Scope: native NIfTI segmentation panel. Existing app navigation and DICOM panels retain their current theme.

Dark navy surfaces, one cyan interaction accent, semantic target colors, 16/15/13 px hierarchy, 8/12/16 px spacing, consistent Lucide stroke widths, ghost icon actions, and 32 px minimum action targets. Fill opacity is immediately available; less frequent settings expand in place. History stays directly accessible. Appearance preferences are separate from voxel/version state.

- Jest: 14 tests, 4 suites passed (including shared mask loading/recovery tests).
- New isolated browser acceptance: direct Stack jump and pulse; physical MPR jump (<1e-3 mm plane error); individual styles; group multiplier; cancellation and restoration; case close during animation; no dirty versions or retained source allocation.
- Existing grouped-mask acceptance: individual visibility, MPR styles, add/save, copy with exact voxels, close/reopen; passed.
- Existing history acceptance: preview, restore, independent target identities, cancellation, MPR; passed.
- Build verifies the existing Stack labelmap and interpolation patches. No dependency upgrade and no DICOM service changes.
- Production verification is read-only. GPU inference and full DICOM editing are not rerun for this UI-only release.

## Release / rollback

`release-display.py` snapshots the current viewer and backend IDs, pins rollback tags, and creates candidate/previous compose overrides. It only replaces the viewer. It refuses to switch if the backend image changed since preparation.

Server commands (from /home/ubuntu/ohif-ai):

    python3 deploy/nifti/release-display.py prepare
    python3 deploy/nifti/release-display.py activate
    python3 deploy/nifti/release-display.py rollback

Rollback files: deploy/nifti-display-release-20260917/previous.yml and release.json. No mask or source data is deleted or migrated.
