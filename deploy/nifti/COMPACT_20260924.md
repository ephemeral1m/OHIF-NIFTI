# Compact segmentation controls — 2026-09-24

## Changes

- Target rows show color, name, saved version and state/actions. Per-target fill opacity now lives inside its display-settings strip alongside outline controls.
- Only one target settings strip opens at a time. Detailed source labels and interaction help use tooltips; repeated saved/editing prose is removed.
- Panel display configuration has one Other targets opacity slider, applied across all groups. Selected targets retain their own style; inactive targets use their group and target opacity multiplied by the context factor.
- 0% context opacity hides inactive fill and outline, including outline-only masks. Changing selection applies the styles and schedules renders immediately. Hidden targets retain their visibility preference.
- These are view preferences for the open case and do not update voxel revisions, history, or files.

## Root cause

The previous per-target inactive-opacity control changed only that target's future inactive appearance. It did not affect the other masks while that target was active. A source-level context control now expresses the requested scope explicitly. Existing Cornerstone active/inactive representation selection is preserved.

## Checks

The browser suite inspects VTK actors' actual opacity transfer functions and outline opacity in Stack and three MPR viewports. It covers cross-group effects, current-target preservation, zero opacity, selecting another target, outline-only masks, compact settings, pulse/cancel and case closure. Unit coverage checks style composition and source-wide scope. Existing group persistence and production read-only checks cover saved annotations.

No backend or DICOM rendering changes. GPU inference is outside this UI-only verification.
